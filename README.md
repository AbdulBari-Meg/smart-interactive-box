# smart-interactive-box
# Smart Interactive Box (نظام الصندوق التفاعلي الذكي)

### 📌 Project Overview / نبذة عن المشروع
An innovative engineering project that combines electronics and coding to design a smart interactive media box. The system detects motion or container opening using digital sensors, triggering interactive lighting and playing custom audio modules.

مشروع هندسي مبتكر يدمج بين الإلكترونيات والبرمجة لتصميم صندوق تفاعلي ذكي. يقوم النظام باستشعار الحركة أو فتح الصندوق عبر حساسات رقمية، ومن ثم تشغيل إضاءة تفاعلية ومقاطع صوتية مخصصة تلقائياً.

---

### 🛠️ Hardware Components / المكونات الإلكترونية المستخدمة
* **Microcontroller:** Arduino Uno / Nano (لوحة التحكم الذكية)
* **Sensor:** Digital Motion / Magnetic Switch Sensor (حساس حركة أو مفتاح مغناطيسي)
* **Audio Module:** MP3 Sound Module (وحدة تشغيل الصوت الرقمية)
* **Output:** Interactive LED Strip / Modules (منظومة إضاءة تفاعلية)

---

### 💻 Software & Logic / الجانب البرمجي
The logic is built using C++ on the Arduino IDE to monitor sensor states constantly. The code ensures instant response and system stability.

تم بناء المنطق البرمجي باستخدام لغة C++ لضمان مراقبة مستمرة لحالة الحساسات، واستجابة فورية فائقة السرعة مع استقرار تام للنظام للإضاءة والصوت عند التفاعل.
